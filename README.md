# Timestamp Genius\n\nTimestamp Genius is an Android 10+ app that follows a script while device playback audio is running and records elapsed time when each script segment finishes.\n\n## Build\nOpen the project in Android Studio with Android SDK 35 and JDK 17, or run:\n`gradle :app:assembleDebug`\n\nThe Debug APK is installable for testing. GitHub Actions runs the matcher unit tests and builds the APK.\n\n## Main buttons\n1. UPLOAD PDF — imports a script PDF. Yellow horizontal separators define the script segments; each segment becomes exactly one timestamp line.\n2. START — prepares the floating control and requests Android permissions needed for screen capture and device playback audio.\n3. LAST PDF RECORDED — opens the most recently generated timestamp PDF.\n4. NEW SESSION — clears the active script/timestamps/PDF reference without deleting saved PDF files.\n\n## Floating control\nSTART begins the timer and live audio recognition.\nSTOP stops capture and preserves timestamps already recorded.\nSAVE creates an A4 PDF in Downloads/ScriptTimestamper/.\nSET LINES edits the yellow guide: line count, box position/size, per-line size, corners, and scroll speed 0–9.\n\n## Recognition\nSpeech recognition is on-device using bundled Vosk English and Hindi models. Screen text uses on-device ML Kit OCR. When an uploaded PDF is present, its extracted segments are the expected script used for fuzzy matching.\n\n## Accessibility\nAndroid Accessibility must be explicitly enabled by the user for automatic active-session scrolling when the target app exposes a scrollable node. Screen OCR remains available without Accessibility.\n\n## Output\nGenerated PDFs use:\n`HH:MM:SS.mmm    script text`\nwith `--:--:--.---` for segments that were not detected. The timestamp is printed once per script segment even when the text wraps.\n\n## Limitations\nSome apps disable Android playback capture. Timestamp Genius reports when the source app blocks capture. Auto-scroll depends on the target app exposing a scrollable accessibility node.
